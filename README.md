## Project Overview 
The Daily Crumb Bakery website is a multi-page, responsive prototype designed for a local artisanal bakery. The project highlights traditional baking services, and streamlines customer interactions through digital forms.

-------

## Website Goals and Objectives 
* **Establish an Online Brand Identity:** Provide a cohesive digital space that allows customers to view our heritage and values.
* **Streamline Customer Inquiries:** Enable seamless online pre-orders.
* **Interactive Forms Engine:** Allow and encourage client feedback.

-------------

## Key Features and Functionality
* **Semantic Web Architecture:** Full integration of HTML structure tags (main, nav, article, header) for accessibility.
* **Multi-Location Contact Registry:** Business profile layouts.
* **Interactive Forms Engine:** For client Feedback and suggestions.

----------------
